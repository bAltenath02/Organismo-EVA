# EXP-002 — Adaptação a uma mudança no ambiente

## Pergunta

Depois de aprender uma relação, a EVA consegue revisar suas previsões quando o
ambiente muda sem aviso?

## Hipótese

Um modelo que dá mais peso às experiências recentes recuperará desempenho em
casos inéditos depois de receber evidências de que a relação mudou. Um modelo
congelado no aprendizado inicial não recuperará esse desempenho.

## Método

O ambiente retorna movimento quando `força / massa` é maior ou igual ao limiar.

1. Na fase inicial, o limiar é `1,0`. A EVA recebe seis experiências e é avaliada
   em quatro situações inéditas.
2. O ambiente muda para o limiar `1,5`, sem qualquer sinal explícito para a EVA.
   Avaliamos seu modelo anterior em quatro situações inéditas.
3. A EVA recebe seis novas experiências. Seu modelo mantém apenas uma janela das
   seis experiências recentes e é avaliado novamente nos mesmos tipos de casos
   inéditos.
4. Comparamos o resultado com uma cópia congelada do modelo da fase inicial.

## Métrica e critério de sucesso

A métrica é acurácia em situações não usadas como experiências. A hipótese é
apoiada somente se, depois das novas experiências, a EVA superar sua própria
acurácia imediatamente após a mudança e a acurácia do modelo congelado.

## Resultado atual

| Momento ou modelo | Acurácia |
| --- | ---: |
| Ambiente inicial | 1,00 |
| Ambiente mudou, antes de novas experiências | 0,50 |
| EVA após adaptação | 1,00 |
| Modelo congelado após a mudança | 0,50 |

Execute o experimento com:

```bash
python src/experimentos/exp_002.py
```

## Limitações e próximo teste

A estratégia de janela recente descarta evidências antigas. Ela é suficiente
para testar adaptação, mas não retenção: se o ambiente voltasse à regra anterior,
este modelo poderia falhar. O próximo experimento deverá separar memória de
longo prazo, contexto atual e detecção de mudança para medir o compromisso entre
reter e adaptar.
