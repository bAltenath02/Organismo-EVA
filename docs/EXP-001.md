# EXP-001 — Movimento sob força

## Pergunta

Depois de observar alguns objetos, a EVA consegue prever o movimento de
combinações de massa e força que nunca encontrou?

## Hipótese

Um mecanismo que ajusta um limiar a partir das relações observadas entre força e
massa terá acurácia superior a um sistema que apenas memoriza os casos exatos de
aprendizagem.

## Ambiente

Cada situação possui `massa` e `força`. O ambiente retorna somente se houve
movimento. A regra interna do ambiente é `força >= massa`; ela não é passada ao
aprendiz como uma regra a executar.

## Método

1. Apresentar seis situações de aprendizagem, com três movimentos e três casos
   sem movimento.
2. A EVA estima um limiar sobre `força / massa` a partir dessas observações.
3. Avaliar seis situações inéditas, sem apresentá-las antes ao aprendiz.
4. Comparar com `MemorizadorExato`, que retém os casos vistos e, nos casos novos,
   prevê a classe mais frequente na aprendizagem.

## Métrica e critério de sucesso

A métrica é acurácia nas seis situações de avaliação. O experimento satisfaz a
hipótese somente se a acurácia da EVA for estritamente maior que a do baseline.

## Resultado atual

Com o conjunto determinístico versionado no código:

| Sistema | Acurácia em situações inéditas |
| --- | ---: |
| EVA (aprendiz de limiar) | 1,00 |
| Baseline (memorizador exato) | 0,50 |

O resultado é reproduzível com:

```bash
python src/experimentos/exp_001.py
python -m unittest discover -s tests -v
```

## Limitações

Este não é um teste de inteligência geral. A relação `força / massa` foi uma
escolha de projeto, portanto é um viés indutivo explícito. O resultado mostra
generalização no ambiente delimitado e contra esse baseline; não demonstra que a
EVA descobriu sozinha todas as variáveis relevantes nem que aprenderá relações
arbitrárias.
